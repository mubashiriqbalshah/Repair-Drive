# Repair Drive — Customer App

Customer-facing React Native app for booking on-demand home repair technicians.

## Stack

- React Native 0.75 + TypeScript
- React Navigation (native-stack + bottom-tabs)
- Zustand (auth/UI state) + TanStack Query (server state)
- Socket.IO client (live order updates, chat)
- axios (REST) with JWT auto-refresh
- i18next (Urdu + English)
- react-native-vector-icons (Material Community)

## Folder structure

```
src/
  api/          REST clients per domain (auth, customer, categories, orders)
  components/   Reusable UI (Button, Input, Card, Screen, Avatar, etc.)
  config/       theme tokens, env
  i18n/         translations (en, ur)
  navigation/   AuthStack + MainTabs + RootStack wiring
  screens/      auth/, home/, order/, profile/
  socket/       Socket.IO client + room helpers
  stores/       Zustand stores (auth)
  utils/        format helpers
App.tsx         entry point: providers + AppNavigator
index.js        AppRegistry registration
```

## Setup (first time)

Prerequisites for actually running on Android:

1. **Node.js 18+** ✓ (you have v24)
2. **Java JDK 17** — required by React Native 0.75
   - Download from https://adoptium.net/
   - Set `JAVA_HOME` env var
3. **Android Studio** — for SDK + emulator
   - Download from https://developer.android.com/studio
   - Install Android SDK Platform 34, Build-Tools 34.0.0
   - Create an Android Virtual Device (AVD) — Pixel 6, API 34
4. **Set ANDROID_HOME** env var to your SDK path (usually `C:\Users\<you>\AppData\Local\Android\Sdk`)

Install dependencies:

```powershell
cd customer-app
npm install
```

Create local config:

```powershell
copy .env.example .env
# Edit .env if backend is running on a different host
```

> The default `API_BASE_URL` is `http://10.0.2.2:4000/v1` — this is the special Android emulator alias for the host machine's `localhost`. On a real device, change to your PC's LAN IP.

## React Native CLI init (still needed)

This folder contains the **source code** but not the native Android folders (because they're generated by RN init and depend on your machine). To create them:

```powershell
# In customer-app/ folder, run:
npx @react-native-community/cli@latest init RepairDriveCustomer --skip-install --version 0.75.4

# This creates a sibling folder. Move the android/ folder into customer-app/:
move RepairDriveCustomer\android .\
move RepairDriveCustomer\ios .\

# Clean up
rm -r -fo RepairDriveCustomer

# Then install deps:
npm install
```

After that, the source code in `src/`, `App.tsx`, `index.js`, etc. already overrides the template defaults.

## Running

Start backend first (in another terminal):

```powershell
cd ..\backend
npm run dev
```

Then in `customer-app/`:

```powershell
# Terminal 1 — Metro bundler
npm start

# Terminal 2 — Build & launch on Android emulator
npm run android
```

- **Geolocation** — `Use current location` button uses placeholder. Add `@react-native-community/geolocation` for real GPS.
- **Photo upload** — UI placeholder only. Add `react-native-image-picker` + Cloudinary upload.
- **Phone calls** — masked-number calling requires Twilio Proxy. Currently a placeholder alert.
- **Push notifications** — FCM integration not yet wired.
- **react-native-config setup** — needs native config (`build.gradle` for Android) once `android/` folder exists.

## Testing the flow

1. Start backend with `npm run dev` (uses in-memory DB or real MongoDB)
2. Run seed if real DB: `npm run seed`
3. Launch this app: `npm run android`
4. Use phone `0301-1234567` (any PK number)
5. Dev OTP auto-fills (`123456`)
6. Enter name → see home screen
7. Tap "AC Repair" → enter problem → "Find Technician"
8. To see an offer come in, you need a technician app side OR use Postman/curl to:
   - Create + approve a test technician
   - Have them call `/technician/orders/<orderId>/offer`
9. Accept the offer → see tracking screen
10. Progress the order via technician/admin API → see status update live

See `../backend/README.md` for the full end-to-end flow guide.
